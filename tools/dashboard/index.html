Pick the dev folder

The game writes it in dev mode (a dotnet build install): %USERPROFILE%\SpireQoL-dev. (or the DevFolder setting, if you set one; never under AppData or Program Files: the browser refuses those). Click Connect, paste that path in the folder picker's address bar, and allow viewing and editing (the page writes your notes and its commands there). Chrome or Edge. The folder is remembered; next time one click reconnects.

Nothing here talks to the network. docs/DEVELOPMENT.md "Dev dashboard" explains every file.
