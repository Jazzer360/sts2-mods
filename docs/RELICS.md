# Relics

Every relic in the game (v0.113.1) and what Spire QoL does for it. Generated by `scripts/coverage-ledger.mjs` from the decompiled game, the settings catalog (`Menu/SettingsCatalog.cs`), the reminder rules (`Data/ChoiceReminders.cs`) and the reviewed reasons (`Diagnostics/RelicTracking.cs`, `Diagnostics/RelicChoiceTracking.cs`); don't edit it, rerun the script.

- **In fights:** the on-card tab it gets (crossed = a red slash), its Relic Counters row, or why nothing is shown. A dash: it has no hook that acts in a fight.
- **Outside fights:** its Run Reminders icon or card-reward row, or why nothing is shown. A dash: it changes no choice outside fights (pickup-only effects, run counters).
- **Gap** marks something worth showing that isn't yet; **unreviewed** marks a relic whose hooks haven't been reviewed (a new game version).
